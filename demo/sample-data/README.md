# CloakSight Demo — Sample Data

This directory contains sample documents and data for testing the CloakSight perception pipeline.

### `receipt/`
Sample receipt images for testing:
- OCR extraction (Phase 4)
- Visual sensitivity detection (Phase 4)
- PII detection in extracted text (Phase 3)

### `pages/`
Sample HTML page snapshots for testing:
- DOM parser (Phase 2)
- PII detection in DOM text (Phase 3)
